02

Tech Stack

React, Vite, Next.js, Docker, Prisma, PostgreSQL, Supabase를 활용한 풀스택 웹 개발 경험.

  • Interface

    React

    컴포넌트 단위로 화면을 조립하고 상태를 다룹니다.
  • Build

    Vite

    빠른 개발 서버와 명확한 번들 흐름을 기준으로 둡니다.
  • App

    Next.js

    라우팅과 렌더링 경계를 의식하며 서비스를 구성합니다.
  • Runtime

    Docker

    환경을 고정하고 실행 조건을 재현 가능하게 만듭니다.
  • Data

    Prisma

    스키마를 코드로 다루며 데이터 규칙을 명시합니다.
  • Store

    PostgreSQL

    관계형 구조를 바탕으로 데이터의 정합성을 지킵니다.
  • Backend

    Supabase

    인증·데이터·API를 묶어 실제 서비스를 빠르게 올립니다.
